  - Features scaled to 0-1 range

  - Dropout for regularization
  - Class-weighted training for imbalance
  - Early stopping on validation loss

Impact:
  ✅ Accuracy: 57% (XGBoost) → 63% (LSTM)
  ✅ Better feature relationship modeling
  ✅ Native class imbalance handling


SOLUTION 3: MODEL SWITCHING API (Flexibility)
──────────────────────────────────────────────
New Endpoints:
  1. POST /api/switch-model

     Response: {"status": "success", "active_model": "lstm", ...}

  2. GET /api/active-model
     Response: {"active_model": "lstm", "model_loaded": true, ...}

  3. GET /api/model-info (enhanced)
     Response: {..., "improvements": {"bias_correction": "enabled"}}

Features:
  ✅ Dynamic model switching without restart
  ✅ Seamless API integration
  ✅ Works with existing /api/predict endpoint
  ✅ Model type returned in prediction response
